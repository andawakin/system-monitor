# Скрипт мониторинга диска и памяти

> Bash-скрипт, который каждые 5 минут через `cron` проверяет свободное место на диске и свободную оперативную память, и пишет предупреждение в лог, если свободного места меньше 10%.

## Описание проекта

Лёгкий инструмент мониторинга для серверов без тяжёлых систем вроде Zabbix/Prometheus — когда нужно быстро контролировать базовые показатели (диск и память) и получать сигнал в лог-файл при приближении к критическому порогу.

## Стек

- Bash
- `df`, `free` (стандартные утилиты Linux)
- cron

## Структура репозитория

```
system-monitor-script/
├── README.md
├── monitor.sh              # основной скрипт проверки
├── crontab.example         # пример записи в crontab
└── logs/
    └── .gitkeep            # папка для логов (сам лог в репозиторий не кладём)
```

## Логика работы скрипта

1. Проверяет использование диска (`df`) для указанной точки монтирования (по умолчанию `/`).
2. Проверяет использование оперативной памяти (`free`).
3. Если свободного места на диске **меньше 10%** ИЛИ свободной памяти **меньше 10%** — пишет предупреждение в лог с меткой времени и текущими значениями.
4. Если всё в норме — пишет обычную информационную запись (опционально, можно отключить, чтобы лог не разрастался).

## Установка и использование

### 1. Скопировать скрипт на сервер

```bash
sudo mkdir -p /opt/system-monitor
sudo cp monitor.sh /opt/system-monitor/monitor.sh
sudo chmod +x /opt/system-monitor/monitor.sh
sudo mkdir -p /var/log/system-monitor
```

### 2. Проверить работу вручную

```bash
sudo /opt/system-monitor/monitor.sh
cat /var/log/system-monitor/monitor.log
```

### 3. Добавить в cron (запуск каждые 5 минут)

```bash
sudo crontab -e
```

Добавить строку (пример также лежит в `crontab.example`):

```cron
*/5 * * * * /opt/system-monitor/monitor.sh >> /var/log/system-monitor/cron.log 2>&1
```

### 4. Проверка, что задача встала в cron

```bash
sudo crontab -l
```

## Пример записи в логе

```
[2026-10-15 14:05:01] INFO: Диск / — свободно 42% | Память — свободно 61%
[2026-10-15 14:10:02] WARNING: Диск / — свободно 8% (меньше порога 10%)!
[2026-10-15 14:15:01] WARNING: Память — свободно 6% (меньше порога 10%)!
```
